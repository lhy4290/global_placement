# 跨國就業薪資智能評估系統 (Global Placement Salary Predictor)

本專案利用 10,000 筆跨國畢業生就業數據，透過隨機森林 (Random Forest) 演算法訓練具備長期記憶的機器模型，並建構前後端分離的智能職涯大數據網頁系統。使用者可依個人學術背景與實務指標，即時推論潛在薪資落點並進行 What-If 職涯優化加薪模擬。

---

## 快速上手與本地執行指南 (How to Run)

本專案專為 Windows 使用者設計了「一鍵啟動自動檔」。請按照以下三個簡單步驟，即可在您的本機電腦上完整復刻並執行本網頁系統：

### 步驟一：下載本專案至您的電腦
點擊本 GitHub 倉庫右上角的 **`Code`** 按鈕，並選擇 **`Download ZIP`**。下載完成後，將壓縮檔解壓縮至您的桌面或任意資料夾。

### 步驟二：初始化 Python 環境與必備套件
本專案運行需要特定的資料科學套件。請打開您的命令提示字元 (CMD) 或網頁終端機，切換至該專案資料夾路徑，並依序執行以下指令建立專屬虛擬環境並安裝套件：

```bash
# 1. 建立專屬虛擬環境 (.venv)
python -m venv .venv

# 2. 安裝本專案必備之網頁與機器學習套件
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 步驟三：一鍵雙擊啟動網頁系統
環境配置完成後，您完全不需要打開任何程式碼編輯器或終端機：

直接進入專案資料夾，用滑鼠雙擊執行 啟動薪資評估工具.bat。

系統將自動在背景啟動 Flask 後端伺服器（進行隨機森林模型的智能記憶讀取/初次訓練）。

稍等 2 秒後，系統會自動在您的瀏覽器中彈出現代化前端網頁 index.html。

您即可自由調整滑桿與下拉選單，點擊按鈕享受 Chart.js 動態互動圖表帶來的智能職涯分析報告！

### 📂核心專案結構 (Project Architecture)
server.py：基於 Flask 框架的後端預測引擎，負責調用機器記憶進行特徵推論與情境模擬。

index.html：優化後的現代化卡片式前端網頁，整合 Chart.js 客戶端動態互動繪圖技術。

global_placement.csv：核心大數據資料庫，供模型第一次啟動時深度學習使用。

requirements.txt：本專案必備套件清單（包含 Flask, Flask-CORS, Scikit-Learn, SciPy 等）。

啟動薪資評估工具.bat：Windows 專屬環境自動對接與一鍵啟動批次檔。
